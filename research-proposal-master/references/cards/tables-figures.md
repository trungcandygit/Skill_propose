# Tier 1 role card: Tables and figures (Seat 2 companion; main session when building exhibits)

Load after `core.md` with `seat2-methods-integrity.md`, and on its own whenever the main session builds or audits a table or figure. Distilled from aer-tables-figures, econ-table, econ-figure, ggplot2, scientific-visualization, nature-figure and the journal file-format snapshots. Each line: rule, why, `→` source. Cite IDs; end with `rules checked: n/total`. Depth rule: render and inspect every table and figure page at final size (core C-60).

## A. Table layout

- **TF-01** Hard conventions: booktabs horizontal rules only (\toprule, \midrule, \bottomrule; in Word no vertical borders), never vertical rules or \hline; caption above tables, below figures; numbered columns; a spanning dependent-variable header; whatever the exporter (modelsummary-style or esttab), the output lands on this anatomy with per-column N and SEs below coefficients. Why: referees read tables first and judge care from them. → `skills/aer-tables-figures/references/exhibit-cookbook.md`
- **TF-02** Main regression table: 3-7 columns progressing simple → rich (raw, controls, unit FE, two-way FE, interacted FE; M1 → M6), the same coefficient row in every column; more than ~7 main-text tables means the contribution is unfocused, move the rest to the appendix. → `skills/aer-tables-figures/SKILL.md#main-results-table-layout`
- **TF-03** Row order: treatment first, then interactions or mechanism, controls last or in the appendix; intuitive, descriptive labels with units ("Household income, 2017 USD"), never raw dataset variable names; first column left-aligned, the rest centred. → `skills/aer-tables-figures/references/exhibit-cookbook.md`
- **TF-04** Indicator rows (Yes/No) for controls, unit FE, time FE, sample; N and R² (or pseudo-R², first-stage F) in every column. → `skills/aer-tables-figures/SKILL.md#column-discipline`
- **TF-05** SE in parentheses below the coefficient, never beside it; never mix brackets and parentheses in one paper; clustering or HAC is stated in the note, not the header. → `skills/aer-tables-figures/SKILL.md#standard-errors`
- **TF-06** Stars defined in every note; one convention across the paper (* p<0.10, ** p<0.05, *** p<0.01, or letters, never mixed); stars never hide magnitudes. → `skills/econ-table/SKILL.md`
- **TF-07** Decimals: round to 2-3 significant digits of the SE and match the coefficient to it, usually 3 decimals, N with 0 decimals and thousands separators; consistent across rows and tables. → `skills/aer-tables-figures/SKILL.md#coefficient-rows`
- **TF-08** Few clusters → wild-bootstrap p-values in the table; weak IV → AR confidence intervals beside or instead of SEs. → `skills/aer-tables-figures/SKILL.md#standard-errors`
- **TF-09** The five canonical tables: summary statistics (≤ 15 rows: N, mean, SD, min, max; median for skewed variables), variable definitions with source and units, balance or first stage, main result, consolidated robustness or heterogeneity. → `skills/aer-tables-figures/SKILL.md#the-five-canonical-tables`
- **TF-10** Heterogeneity is shown as interaction coefficients, not many subgroup tables, unless subgroups are the point. → `references/r-data.md#table-layout-modelsummary--etable--booktabs`
- **TF-11** Robustness table: first column repeats the headline estimate; one row or column per check; N changes flagged; one main-text robustness table, the rest in the appendix. → `skills/aer-robustness/references/robustness-menu.md`
- **TF-12** Summary statistics show N, T and N×T for panels, % missing per variable, and normalized differences for balance rather than t-tests. → `skills/econ-stats/SKILL.md`
- **TF-13** Every number in a table is discussed or needed; a reader can write down the exact regression from the table alone; every exhibit must displace at least 200 words of explanation to pay for itself. → `skills/econ-write/SKILL.md`
- **TF-14** Each key result appears in a table or a figure, not both, unless the journal asks; coefficient plots beat tables when comparing 8 or more specifications. → `skills/econ-write/SKILL.md`

## B. Table and figure notes (short, self-contained)

- **TF-15** User rule (overrides the longer note templates in the sources): every table and figure note is at most 2 short sentences and about 30 words; never repeat results already given in the text (interaction values, CIs, p-values belong in the text). Why: the user wants notes short and uncluttered; long notes bury the essentials. Pack the essentials into those 2 sentences and move everything else out: sample, N, FE and controls go in the table's indicator rows; variable definitions go in the appendix definitions table, cited by number. `scripts/check_docx_style.py` flags longer notes.
- **TF-16** Each note, within its 2 sentences, still states the estimator, SE type with cluster level ("clustered by firm", never bare "robust"), the star legend, and the data source or sample period; a note that drops one of these fails. Example: "Notes: Fixed-effects estimates; standard errors clustered by firm in parentheses. * p<0.10, ** p<0.05, *** p<0.01; variables defined in Table A1." → `skills/aer-tables-figures/references/exhibit-cookbook.md`
- **TF-17** Cover the body text and ask: can a referee read the exhibit alone (note + indicator rows + labels + cited definitions table)? Any undefined term, acronym or column header ("Full controls") fails. → `skills/aer-consistency/references/audit-checklist.md#pass-6--exhibit-self-containedness`
- **TF-18** No "Notes: See text"; no equations, results narration, motivation or repeated method description in a note. → `skills/aer-tables-figures/SKILL.md#anti-patterns`
- **TF-19** Sample restrictions, winsorization percentiles and deviations in N (balanced panel, IV subsample) are disclosed, in the indicator rows or the text when the note is full. → `skills/econ-stats/SKILL.md`

## C. Table files and LaTeX/Word hygiene

- **TF-21** Generate tables from model objects (modelsummary, etable, esttab), never retype numbers; one call exports .tex, .docx and .xlsx. Why: hand-copied cells are where mismatches start. → `skills/econ-table/SKILL.md`
- **TF-22** LaTeX: a body-only file with the full table environment for \input{} plus a standalone file for spot-checks; avoid siunitx S columns (use dcolumn or c); no raw Unicode such as ≥ or → in generated .tex (use $\geq$, $\rightarrow$). → `skills/econ-table/SKILL.md`
- **TF-23** Width: 7 or more columns → landscape and \footnotesize; 5-6 columns → narrow first column, \footnotesize, reduced tabcolsep; no table exceeds the page or wraps awkwardly. → `skills/econ-table/SKILL.md`
- **TF-24** Word deliverables: real Word tables (not images), no vertical borders, notes as a paragraph under the table, numbering identical to the text. → `skills/aer-tables-figures/SKILL.md#pre-submission-checklist`

## D. Figure content and honesty

- **TF-26** Never alter, hide, invent or selectively enhance data to improve a figure; do not silently connect missing observations, suppress inconvenient points, upsample images as if detail increased, or tune axes or dual axes to exaggerate a conclusion; do not use interpolation or smoothing to imply observations between measured points; distinguish missing, zero and censored; never let missing values default to the low end of a colour scale. → `skills/scientific-visualization/SKILL.md`
- **TF-27** Never show a point estimate without uncertainty; name the interval (SE, 95% CI, clustered or not), n and the unit of replication; do not add error bars mechanically; show raw observations when feasible and do not jitter points so far that their category or value becomes ambiguous. → `skills/econ-figure/SKILL.md`
- **TF-28** Honest axes (avoid visual deception): bars start at zero; points and lines encode position, so a nonzero axis limit can be valid, but show enough context, disclose breaks, make a meaningful nonzero reference explicit, and avoid choosing limits solely to magnify a small effect; do not extend axes far beyond the observed data to suppress variation; a logarithmic axis names its base and declares a policy for zero and negative values, never silently discarding them. → `skills/scientific-visualization/references/publication_guidelines.md`
- **TF-29** No pie charts (never in academic economics papers), no 3D or perspective bars and surfaces (occlusion and perspective distort values; use 2D alternatives), no dual axes (use aligned panels; if unavoidable justify the units and do not engineer correlation); scale area, not radius. → `skills/econ-figure/SKILL.md`
- **TF-30** Reference lines: zero line on coefficient plots, cutoff on RD plots, treatment date and omitted period (-1) on event studies; event studies always show pre-period coefficients, the design's credibility exhibit. → `skills/aer-tables-figures/SKILL.md#figures`
- **TF-31** Begin with the one sentence the figure must establish, a core conclusion with a verb ("X is associated with lower Y"), not "Results", then choose the few evidence roles a skeptical reader needs; do not begin with the number of datasets, metrics or panels, do not start from a favourite template, and do not plan one figure per source table. One main claim per figure; split panels rather than overlaying six lines. → `skills/nature-figure/references/figure-contract.md`
- **TF-32** Do not add unsupported causal claims or invented values in titles, labels or legends; do not hide a result that changes the conclusion merely because it is negative or complicates the layout. → `skills/nature-figure/references/multipanel-evidence-architecture.md`
- **TF-33** Figure types for econometrics: event study, coefficient plot, binned scatter or binsreg, rdplot, density comparison, SCM gap with placebo lines, Bacon decomposition, specification curve (sorted estimates plus choice indicators). If the design does not support a figure (no event study for a cross-section), say why instead of dropping it silently. → `skills/econ-figure/SKILL.md`
- **TF-34** Multi-panel evidence: each panel is a different necessary sentence in the same visual argument (covering one panel removes a distinct inferential step), not parallel mini-stories or one comparison mirrored across metrics, and not unrelated metric panels; the primary evidence gets the hero panel or clearest axis while controls and robustness panels are visually quieter; panel letters mark reading order, not universal functions; do not copy a published paper's panel count; a representative example explains or challenges the aggregate, never a decorative anecdote; add a setup schematic only when readers need it to interpret the evidence; a later figure asks a deeper or different question than the one before. → `skills/nature-figure/references/multipanel-evidence-architecture.md`

## E. Figure style

- **TF-35** Never ship a default matplotlib or ggplot theme (always customise: theme_classic or theme_minimal); no gridline clutter, borders, drop shadows, decorative icons, patterns, coloured text or chartjunk; every ink element must carry information; legend inside the plot or below, without a box. → `skills/econ-figure/SKILL.md`
- **TF-36** No title inside the plot area; the caption carries the title. Why: an in-plot title duplicates the caption and wastes space. → `skills/proofreading/SKILL.md`
- **TF-37** Fonts sans-serif (Arial or Helvetica) or the journal body font, one family across figures, at final printed size at least 9 pt for axis labels when the journal is unknown or AER-family; journals with their own rule (Nature 5-7 pt, Elsevier about 7 pt, PLOS 8-12 pt) follow that rule; compare the rendered text size with the available slot at final size, do not rely on the source font number alone. → `skills/aer-tables-figures/SKILL.md#format-rules`
- **TF-38** Lines thick enough to read in print and when scaled down: at least 0.5 pt for data and 0.75 pt for axes at final size; avoid dotted lines that disappear when reproduced and dashes for volatile series. → `skills/econ-figure/SKILL.md`
- **TF-39** Axis labels descriptive with units ("Return volatility (annualised, %)"); colourbars labelled with units and transformed scale; tick values in round data steps; do not apply automatic title-casing (.title()), which corrupts canonical names. → `skills/master-academic-paper-skill/rules/06_figure_synthesis_and_visuals.md`
- **TF-40** Colour: no colour-only encoding (colour must not be the only visual means of conveying information, nor matching colours the only association cue): add marker, linetype, label or outline; figures stay legible in grayscale and to colour-blind readers; do not rely on red/green combinations or similar hues as sole identifiers; at most 3-4 colours; use an accessible palette (viridis, cividis, Okabe-Ito, Paul Tol); qualitative palettes for unordered categories, never implying order and never interpolated; hue separates groups while lightness should not imply an unintended ranking; do not repurpose a sequential light-to-dark palette as categorical colours; no rainbow scale for ordered data; a diverging map only when the centre has scientific meaning, not merely because values are positive and negative. → `skills/scientific-visualization/references/color_palettes.md`
- **TF-41** Contrast (WCAG 2.2 as web guidance): graphical objects required to understand content have at least 3:1 contrast against adjacent colours (SC 1.4.11 AA), text 4.5:1, large text 3:1; several light colours do not reach 3:1 against white and most qualitative schemes do not stay separable in grayscale; inspect grayscale, but a grayscale conversion is not a complete colour-vision simulation; check at final physical size. → `skills/scientific-visualization/SKILL.md`
- **TF-42** Multi-panel layout: panel labels (a), (b), (c) or the journal's style; aligned plot areas (patchwork/cowplot) without confusing unequal tick-label widths with a shifted data rectangle; do not force equal panel sizes when inferential importance differs; move overlapping text or alter the layout rather than hiding it with an opaque white box; automated checks do not replace a panel-by-panel audit of uncertainty, salience, spacing and ambiguity; do not approve a figure from a whole-page glance. → `skills/nature-figure/references/qa-contract.md`
- **TF-43** ggplot2 4.x API: S7 objects use `@`; theme(ink, paper, accent); coord_transform not coord_trans; geom_errorbar(orientation = "y") not geom_errorbarh; set width and height in ggsave, never by resizing in the document. → `skills/ggplot2/SKILL.md`
- **TF-44** After export, open the PDF or SVG and verify that text can be selected, labels do not overlap, baselines do not look stronger than the primary evidence, and the figure still reads at final printed size; inspect the actual figure because metrics do not encode which series should dominate attention. → `skills/nature-figure/references/qa-contract.md`

## F. Figure notes and in-figure text

- **TF-45** Figure notes sit below the figure, start "Notes:", and stay within 2 sentences (TF-15): estimator or method, omitted/reference category, CI type, and sample with N; sample restrictions beyond that go to the text. → `skills/aer-tables-figures/SKILL.md#what-notes-must-include`
- **TF-46** A caption is readable away from the text and says what line styles mean, but does not narrate results or duplicate methods; captions are never one-word fragments; no terminal full stop needed on a caption title. → `skills/nature-figure/references/figure-legend-conventions.md`
- **TF-47** User rule: little text inside figures. Why: the user wants uncluttered figures. Short axis labels with units, no in-plot title, no subtitle, no paragraphs or long annotations, at most one short label per highlighted element, a legend only when direct labels cannot do the job, no repeated text that the caption already carries. → `skills/econ-figure/SKILL.md`

## G. Files

- **TF-50** Embed fonts (cairo_pdf in R; `pdf.fonttype = 42` in matplotlib); keep text editable, not outlined or rasterized. → `skills/nature-figure/references/nature-article-requirements.md`
- **TF-53** Files: one figures/ folder, zero-padded names (fig01_event_study.pdf) so \includegraphics{} or Word links never point to missing or scattered files; a header comment in each script listing the figures it writes; never two scripts writing the same file; record data path, transformations and seed; never overwrite raw data or images. → `skills/econ-figure/SKILL.md`

## H. Resolved conflicts

- **TF-62** Figure title: none inside the plot (proofreading, aer-tables-figures) vs Nature legends that start with a title sentence: the title lives in the caption or legend, never in the plot area.
- **TF-63** Note length: sources ask notes to list many items "in complete sentences" (exhibit-cookbook, aer-consistency pass 6) vs the user's 2-sentence cap (TF-15): the user wins (core C-50); self-containedness is kept by moving detail into indicator rows and an appendix definitions table, not by lengthening notes.

- **TF-64** User rule: table text matches the manuscript's existing tables (10 pt here) and never goes below 9 pt; wide tables shorten headers, drop redundant columns, or move to landscape before shrinking the font; check the rendered page for words broken across lines. Why: the user found 7.5-8 pt tables hard to read (BAI_VALUATION, 2026-10-24).
