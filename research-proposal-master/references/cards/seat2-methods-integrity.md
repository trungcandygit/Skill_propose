# Tier 1 role card: Seat 2 (methods + integrity)

Scope: numbers, reproduction, coding, identification, statistics, citations.

Load after `core.md`, together with `tables-figures.md`. Used by the Seat 2 panel agent and by the main session whenever it re-estimates models, writes R code, checks numbers, or verifies citations. Each line: rule, short why, `→` source. Cite IDs in findings; end with `rules checked: n/total`. Depth rule: core C-60 to C-62 (rerun, recompute, render everything; no sampling).

## A. Numbers against tables (run the scripts first, then the manual passes)

- **S2-01** Run `scripts/check_numbers.py` and `scripts/check_crossrefs.py` before reading by eye; the manual passes start from zero dangling references; rows must be OK or PASS before handoff. Why: unstructured re-reading finds style and misses arithmetic. → `skills/aer-consistency/references/audit-checklist.md`
- **S2-02** Headline register: every repeated number (abstract, introduction, results, conclusion, letter) traces to one table cell to the digit including SE, and all quote the same specification. → `skills/aer-consistency/references/audit-checklist.md#pass-1--numbers-in-text-vs-tables`
- **S2-03** Sample funnel: raw N minus documented drops equals analysis N; Table 1 N equals main-table N for the matching spec; subsample Ns sum correctly; obs = units × periods; any deviation is explained in notes and text. → `skills/aer-consistency/references/audit-checklist.md#pass-2--sample-funnel-consistency`
- **S2-04** Units: log points vs percent (exact conversion when |β| > 0.10), percent vs percentage point on rates, standardized effects name the SD, one currency base year, sign narration on inverted scales. → `skills/aer-consistency/references/audit-checklist.md#pass-3--log-points-vs-percent-conversions`
- **S2-05** Stars match |b/se| (1.65 / 1.96 / 2.58); prose "significant at X%" matches the table; one star convention across the paper. → `skills/aer-consistency/SKILL.md`
- **S2-06** Cross-references: no "Table ??"; exhibits numbered in order of first mention; every exhibit cited; section, appendix and equation references survive renumbering; then check the semantic layer (does Table 4 show what the sentence claims?). → `skills/aer-consistency/references/audit-checklist.md#pass-4--internal-cross-references`
- **S2-07** Terminology: one name per variable and concept everywhere; the outcome named in the abstract is the one in the tables. → `skills/aer-consistency/references/audit-checklist.md#pass-7--terminology-consistency`
- **S2-08** Diff the table files in the manuscript against the replication output tables: they must be the same files the code produced, not lookalikes; report rows as AUDIT | PASS/FAIL | DETAIL and fix every FAIL; "close enough" is not accepted. → `skills/aer-consistency/SKILL.md`

## B. Reproduction

- **S2-10** Tolerances: point estimates |diff| < 0.01, SEs < 0.05, p-values same significance level, percentages within 0.1 pp, counts exact. → `skills/audit-reproducibility/SKILL.md#phase-4-tolerance-check`
- **S2-11** Outcomes: PASS, FAIL, EXPLAINED (only with a concrete named alternative spec, e.g. clustering df, bandwidth rule, seed), UNMATCHED; a blank or vague note never downgrades a FAIL; a display that cannot be found is a FAIL, not a skip; do not promote UNVERIFIED claims to PASS without running the actual numeric audit. → `skills/audit-reproducibility/rules/replication-protocol.md`
- **S2-12** Two displays of one number (paper and letter, paper and slides) must match after rounding; do not reconcile a horizontal disagreement by hand-editing whichever display looks wrong (two displays that disagree say nothing about which is right): re-derive both from the output. → `skills/audit-reproducibility/SKILL.md#phase-4c-horizontal-check`
- **S2-13** Re-run the analysis scripts on a copy of the data in a scratch folder and diff the outputs; translate line by line during replication, do not "improve" it; on a mismatch do not proceed to extensions: isolate which step introduces the difference, check common causes (sample size, SE computation, default options, variable definitions) and document the investigation even if unresolved. → `skills/audit-reproducibility/rules/replication-protocol.md`
- **S2-14** Replication package: code reproduces every result without manual steps, code and data kept apart, seeds and versions recorded (renv lockfile, set.seed, sessionInfo), README in AEA format; audits are read-only on the package; keep only steps that change a claim, not a chronological notebook. → `skills/audit-replication/SKILL.md`
- **S2-15** A claim contested twice (EXPLAINED twice, never corrected) is surfaced prominently, not left quiet. → `skills/audit-reproducibility/SKILL.md`

## C. Data handling (R)

- **S2-17** Never overwrite raw data or tabular files; label variables and values, keep a data dictionary or codebook, and document every transformation explaining why. → `skills/data-cleaning/SKILL.md`
- **S2-18** Recode sentinel codes (-99, -88) to NA first; decide missing data per variable; report % missing per variable; test whether missingness is related to covariates before listwise deletion. → `references/r-data.md#hard-rules`
- **S2-19** Check key uniqueness before any merge; merge with join_by(), declare cardinality (`relationship = "many-to-one"`, `unmatched = "error"`, `na_matches = "never"`); assert nrow unchanged after the merge. Why: row inflation silently changes N. → `skills/tidyverse-patterns/SKILL.md`
- **S2-20** Outliers: flag first (|z| > 4), do not drop silently; winsorize (1/99, document the percentiles, optionally within industry-year) or trim at disclosed percentiles rather than delete. → `skills/econ-stats/SKILL.md`
- **S2-21** Construct variables: never log(0), use asinh() or log(pmax(x, 1)) or log(x+1) and state the interpretation; deflate nominal values by CPI to a base year; arrange(id, year) then group_by(id) before lag, lead or diff; build first_treat and rel_time for staggered designs. → `references/r-data.md#hard-rules`
- **S2-22** Log the sample construction (step, N after each filter) and run a data contract (shape, types, missingness, key duplicates, panel balance) before modelling; estimators drop NA rows silently; never use NA-unsafe negated filters (negation silently drops NA; use filter_out() or explicit NA handling). → `skills/empirical-analysis-r/SKILL.md`
- **S2-23** Finance data: record source, retrieval date and adjustment for splits, dividends and bonus shares; lag accounting data 3-6 months to avoid look-ahead bias; treat banks separately; factor data for non-US markets must come from a local construction or a clearly cited source, do not reuse US factors for Vietnam without saying so. → `references/methods-gap-fill.md#f-vietnamese-and-asean-data`
- **S2-24** Thin trading and daily price limits (HOSE, HNX) distort returns: use Dimson or Scholes-Williams betas or longer windows and report the share of zero-return days. → `references/methods-gap-fill.md#f-vietnamese-and-asean-data`
- **S2-25** R code: native pipe; prefer join_by() over by = c("a" = "b"); never sapply (use map_*); never grow objects in loops (pre-allocate vector("list", n) or use map()); 2-space indent, never tabs, lines < 80 chars; project skeleton with raw/ never overwritten, renv lockfile, set.seed(), relative paths, no setwd(); feols(y ~ x | unit + year, cluster = ~unit), not lm with factor dummies; estimators return objects passed straight to modelsummary or etable, never hand-rolled tables; do not optimize without measuring (benchmark first). → `skills/r-style-guide/SKILL.md`

## D. Identification and estimation

General
- **S2-27** Before estimating, record the route card (estimand, design, focal outcome and treatment, unit of observation, data source, known quality issues) and write the estimating equation, the identifying assumption in one sentence (in the introduction, not a footnote), the threats and the fallback estimator; use the methods reference first, since it fixes the estimand, diagnostic, inference method and citation the manuscript must report. → `skills/aer-identification/SKILL.md`
- **S2-28** Never control for post-treatment variables or mediators (bad controls); do not include every determinant of Y; do not confuse instruments with controls; covariate adjustment is for efficiency and the main result must hold without it. → `skills/ols-regression/SKILL.md`
- **S2-29** SE choice follows diagnostics: HC for cross-section, cluster at the level of treatment variation (not the individual by reflex), Newey-West/HAC for time series, Driscoll-Kraay under cross-sectional dependence, two-way cluster when both; state it in the note. → `skills/panel-data/SKILL.md`
- **S2-30** Fewer than about 50 clusters, unbalanced cluster sizes, one or few treated clusters, small N or concentrated leverage: wild cluster bootstrap or randomization-inference p-values are required; fewer than 15 clusters is a pathology flag. → `skills/aer-robustness/references/robustness-menu.md`
- **S2-31** Use validated estimators, do not hand-roll the design (att_gt, sunab, did_imputation, ivreg with AR, rdrobust, synth with placebo, boottest, HonestDiD, Oster delta, E-value). → `skills/aer-identification/SKILL.md`
- **S2-32** Do not present OLS-with-controls as the main result and IV or RD as "robustness"; two strategies sharing the same identifying variation are not independent confirmation; identification answers whether X causes Y, mechanism answers why, and mechanism evidence should not weaken the identification of the main effect. → `skills/aer-identification/references/estimator-playbook.md`
- **S2-33** R-squared is not evidence of correct specification or causality; judge by the coefficient and its SE; two-stage SEs must be corrected for the two-stage estimation (software does this, hand-built second stages do not). → `skills/econ-write/SKILL.md`
- **S2-34** Identification gate: do not advance to robustness or writing until every required diagnostic for the chosen design is run and reported. → `skills/aer-identification/SKILL.md#identification-gate`

Panel FE / RE / dynamic GMM
- **S2-35** Test before choosing: Hausman (p < 0.05 → FE), Mundlak/CRE as an alternative; never RE untested; FE estimates within-unit variation and cannot identify time-invariant regressors. So count the units that switch the regressor (and, for an interaction, the units observed on both sides of the treatment date) and report the count when one side is thin. → `skills/panel-data/SKILL.md`
- **S2-36** Report which FE are included (entity, time, both, interacted), the FE F-test, Hausman result, N units, T, total obs and balance. → `skills/panel-data/references/panel-reference.md`
- **S2-37** Lagged DV with FE and short T has Nickell bias: use difference or system GMM; declare endogenous, predetermined and exogenous variables and the lag range; collapse instruments. → `references/methods-gap-fill.md#b-dynamic-panel-gmm-difference-and-system`
- **S2-38** GMM reporting: obs, groups, instrument count ≤ groups; AR(1) test should be significant (first-order autocorrelation expected) and AR(2) insignificant (no second-order autocorrelation); Hansen/Sargan J p between about 0.10 and 0.90 (near 1.00 signals proliferation, do not over-identify); difference-in-Hansen for level instruments; Windmeijer-corrected two-step SEs. → `references/methods-gap-fill.md#b-dynamic-panel-gmm-difference-and-system`
- **S2-39** GMM robustness: lagged-DV coefficient lies between FE (lower) and pooled OLS (upper) bounds; vary lag range, collapse vs not, one-step vs two-step. → `references/methods-gap-fill.md`

DiD and event study
- **S2-41** Staggered adoption with heterogeneous effects: do not run plain TWFE with a single treat dummy on staggered data (it can flip sign); always use Callaway-Sant'Anna (att_gt with never-treated controls), Sun-Abraham (sunab), BJS imputation or dCDH and explain why; show the Goodman-Bacon decomposition. → `skills/did-analysis/SKILL.md`
- **S2-42** TWFE is valid only with simultaneous treatment timing, never-treated controls and plausibly homogeneous effects; do not stretch the 2x2 label over quietly staggered adoption; already-treated units are never controls; do not pick the control group after seeing outcomes. An interaction with a time-varying treatment keeps the treatment main effect (`skills/econ-full-python/references/07-further-analysis.md`) and absorbs the moderator's common time path with moderator-by-year fixed effects or group-specific trends (`skills/econ-stata-reference/references/difference-in-differences.md`); few treated clusters follow S2-30. → `skills/aer-identification/references/estimator-playbook.md`
- **S2-43** Parallel trends: always include the event-study figure (reviewers expect to see pre-trends), from the robust estimator, with pre-period coefficients shown, reference period -1 and endpoint binning stated in the note; a joint test on all leads (do not test each lead separately and call it joint), Roth power and HonestDiD bounds; contrast with the naive TWFE event study when they disagree; do not assemble leads and lags by hand on staggered data; a flat plot alone proves nothing. → `skills/aer-identification/references/estimator-playbook.md`
- **S2-44** Discuss anticipation, Ashenfelter dip and spillovers; cluster at the treatment-assignment level; show cohort heterogeneity before aggregating; bin endpoints openly; use a triple difference (DDD) when a subgroup within treated and control units should be differentially affected. → `skills/did-analysis/SKILL.md`
- **S2-45** Placebos are required for DiD, event studies, SCM and IV: fake treatment date in the pre-period (effect should be zero), cross-unit placebo assigning treatment to randomly chosen never-treated units (the placebo distribution should bracket zero), an outcome that should not respond; any placebo comparable in size to the main effect means the design is compromised, do not explain it away in a footnote. → `skills/aer-robustness/references/robustness-menu.md`

IV and shift-share
- **S2-47** Report the first stage with effective F (Olea-Pflueger); do not cite F > 10 as evidence; for F < 50, 2SLS confidence intervals are unreliable and Anderson-Rubin sets are required, not optional; show OLS next to IV and do not hide the reduced form; Wu-Hausman for endogeneity. → `skills/aer-identification/SKILL.md`
- **S2-48** Relevance: Z must be correlated with the endogenous regressor. Exclusion cannot be tested statistically: make a convincing argument in one sentence in the introduction, defend it with narrative, a placebo outcome the instrument should not predict, and sensitivity (Conley); "we control for X" is not a defence. → `skills/iv-estimation/SKILL.md`
- **S2-49** IV estimates LATE for compliers, not ATE; Sargan/Hansen only when over-identified; compare 2SLS and LIML. → `skills/iv-estimation/references/iv-reference.md`
- **S2-50** Bartik / shift-share: choose shares-exogeneity (Rotemberg weights) or shocks-exogeneity (effective number of shocks, shock-level SEs), never hand-wave between them; show pre-trends of outcomes against the instrument and balance of shares or shocks; standard errors account for the exposure-shares structure (do not cluster only by region when shocks identify). → `skills/aer-identification/references/estimator-playbook.md`

RDD, SCM, matching
- **S2-52** RDD: local linear, triangular kernel, MSE-optimal bandwidth, robust bias-corrected CI; do not fit polynomials of order above 2; binned scatter; never skip the density/manipulation test because the plot "looks smooth" (a failure compromises the design); covariate balance and placebo cutoffs; bandwidth sensitivity at 50/75/125/150% (never one hand-picked bandwidth); donut RDD if bunching; no extrapolation from the cutoff. → `skills/rdd-analysis/SKILL.md`
- **S2-53** SCM (Abadie 2021 checklist): pre-RMSPE below about 5% of the pre-period mean; do not present SCM with no placebo inference (in-space and in-time placebos, MSPE-ratio rank p-value); full donor pool and weights (discuss donors above 10%); do not keep donors exposed to spillovers in the pool; do not tune the predictor set after seeing the post-period gap; many treated units → augsynth, gsynth, synthdid. → `skills/synthetic-control/SKILL.md`
- **S2-54** Matching / PSM: common support shown, balance table with |SMD| < 0.1 after matching; normalized differences |Δ| < 0.25 for descriptive balance (not t-tests, which reject with large N). → `skills/iv-estimation/references/iv-reference.md`

Time series, quantile, asset pricing, surveys, Bayesian
- **S2-56** Test unit roots (ADF and KPSS) before regressing series on each other; I(1) without cointegration → differences; cointegrated → VECM; mixed orders → ARDL; structural breaks (Zivot-Andrews) can mimic a unit root. → `skills/time-series/SKILL.md`
- **S2-57** Quantile regression: bootstrap or cluster-bootstrap SEs (≥ 1,000 reps), a grid of quantiles with a figure against OLS, an equality test across quantiles; panel FE needs a dedicated method (MMQR, Canay) named and justified; avoid quantile crossing problems by rearrangement and say so if it occurs. → `references/methods-gap-fill.md#c-quantile-regression`
- **S2-58** Event studies on returns: stated estimation and event windows, market or factor model, robust tests (BMP, Kolari-Pynnönen for clustered events) plus a rank or sign test; check confounding and overlapping events. → `references/methods-gap-fill.md#d-event-study-and-asset-pricing-tests`
- **S2-59** Factor tests: GRS for alphas, Fama-MacBeth with Newey-West t and Shanken correction; portfolio sorts value- and equal-weighted with long-short Newey-West t. → `references/methods-gap-fill.md`
- **S2-60** Survey constructs: alpha ≥ 0.70, CR 0.70-0.95, AVE ≥ 0.50, HTMT < 0.85/0.90, CFI/TLI ≥ 0.90, RMSEA and SRMR ≤ 0.08; PLS paths bootstrapped 5,000 times; no model changes from modification indices without theory; common-method bias by full-collinearity VIF < 3.3. → `references/methods-gap-fill.md#a-survey-scales-efa-cfa-pls-sem`
- **S2-61** Nonlinear models and interactions: coefficients are not effects; report average marginal effects or comparisons with their uncertainty; Bayesian results say clearly which statements are credible intervals and avoid mixing them with frequentist language. → `skills/marginaleffects/SKILL.md`

## E. Statistics hygiene, robustness, specification search

- **S2-63** Every estimate carries uncertainty (SE or 95% CI); report 95% CIs with p-values for headline and null results; prefer effect sizes over stars; p values should not carry the full evidential burden (effect estimates, uncertainty, design quality and reproducibility matter). → `skills/aer-robustness/SKILL.md`
- **S2-64** Nulls: do not report "not significant" as "no effect" without power or the MDE and a tight CI; provide the exact p value or state the reporting threshold; do not mine subgroups outside the pre-analysis plan without labeling them exploratory; account for the design effect when assignment is clustered. → `skills/aer-identification/references/estimator-playbook.md`
- **S2-65** Family-wise correction (Romano-Wolf) is required whenever more than one outcome, subgroup or treatment arm supports a headline claim; heterogeneity is required when the mechanism claim predicts where the effect concentrates (the referee will check it concentrates where the theory says, e.g. larger in low-credit-access units if the channel is credit), theory-predicted, labelled pre-specified or exploratory, never mined across every demographic. → `skills/aer-robustness/references/robustness-menu.md`
- **S2-66** Robustness table: first column is the headline estimate, one row per check, N changes flagged; checks probe the identifying assumption and the two or three counterarguments a smart referee will raise, not things nobody doubts (year FE already in the spec), and not a 30-page appendix of noise; never add robustness the morning before submission, never highlight 2 of 20 specs, never "available upon request". → `skills/aer-robustness/references/robustness-menu.md`
- **S2-67** Coefficient stability claims are scaled by R-squared movement (Oster delta); sensitivity analysis (Oster, E-value, HonestDiD) is required for any observational design whose headline survives on "we control for X"; "barely moves" means nothing if the controls explain nothing. → `skills/aer-robustness/references/robustness-menu.md`
- **S2-68** Fail signals: the result lives in one specification, one unit, period or subset carries it (a leave-one-out check is required whenever one plausibly dominates), or a mechanism test contradicts the main sign on a subsample while presented as confirming. → `skills/aer-robustness/references/robustness-menu.md`
- **S2-69** Specification search (optional by default, required when the result is contested, counterintuitive, or a referee alleges specification search): the ledger of all specifications tried must be complete before naming a "best" spec; a best spec with pathology flags is not a finding; a pre-registered spec that is null while the best is significant is a fragility result to report. → `skills/specification-search/SKILL.md`
- **S2-70** Audit direction-aware (one-sided when the hypothesis has a sign); the null draw must destroy the treatment's relationship with the outcome while preserving everything else: permute whole treatment paths (cluster_permute) for panels and staggered designs, never plain permute (null too tight). → `skills/specification-search/SKILL.md`
- **S2-71** p-hacking tests run on distributions of many results; a flag is a reason to look, never a finding that a paper is p-hacked; p-curve shape tests need ≥ 15 significant results; bunching and density-jump tests need enough mass near the threshold and return a note, not a p-value, when they do not; use the counterfactual caliper test. → `skills/phack-detection/SKILL.md`
- **S2-72** Unit of analysis: the manuscript should define the independent unit (firm, bank, country) as n; do not count repeated observations of the same unit as independent replication; a row-wise CI or a fixed seed does not account for within-unit dependence. → `skills/nature-statistics/SKILL.md`
- **S2-73** Statistical reporting complete enough for editors and referees to assess the work at initial submission: design, unit and n, test or model, correction for multiplicity, effect size with uncertainty, exact p or stated threshold, software and version, exclusions; figures expose n, error-bar meaning, test, correction and whether points are independent units; missing items become author questions, never invented (no invented p values, degrees of freedom, correction methods, preregistration or power calculations), and no post-hoc exclusions unless the user supplied them. → `skills/nature-statistics/references/statistical-reporting.md`
- **S2-74** Never write that a new analysis was performed unless the user supplies the result or asks you to run it on data; when auditing, do not accuse the authors: state the risk and the fix, and check that proposed wording avoids causal or mechanistic overclaiming. → `skills/nature-statistics/references/reviewer-checklist.md`
- **S2-75** Every estimator report states: estimator and software with version, sample, N and clusters, assumption, diagnostics and results, robustness, effect size with uncertainty, limitations. Do not claim a journal "requires this exact test" unless its instruction actually says so. → `references/methods-gap-fill.md#h-what-to-report-for-every-method`

## F. Citations and references

- **S2-77** Verify every newly added or changed reference promptly, when adding it (do not wait until finished): existence (DOI resolve, publisher, CrossRef, then DBLP/Semantic Scholar; if only Google Scholar finds it, mark it manual verification and do not treat the BibTeX as final until metadata is checked elsewhere), metadata (authors, year ±1 for preprints, title, journal, volume, pages), DOI included when one exists. → `skills/citation-verification/SKILL.md`
- **S2-78** Claim support per occurrence: when citing a specific claim, confirm the claim actually appears in the cited paper (Supported / Partially / Not supported / Unconfirmed / Not found); never cite X for Y when X found Z. → `skills/reference-verify/SKILL.md`
- **S2-79** Check both directions: every in-text citation is in the reference list and every entry is cited (flag orphan entries left over from a cut paragraph); author spelling and year identical (a 2020 paper cited as 2019 is a FAIL); the same work entered twice under two keys is flagged. Use `scripts/check_crossrefs.py`. → `skills/aer-consistency/references/audit-checklist.md#pass-5--citation-two-way-match`
- **S2-80** Explain every "not found": what was searched, what was found instead, likely cause, fix; check whether working papers have been published and whether any reference was retracted. → `skills/reference-verify/SKILL.md`
- **S2-81** Fix safely: always create a timestamped backup on the first applied edit; keep the citation command shape; never delete a sentence whole if that leaves the paragraph ungrammatical or removes a substantive claim (rewrite instead); auto-apply only with explicit opt-in; never invent a replacement cite key: it must already exist in the .bib or point to a paper actually verified online. → `skills/reference-verify/SKILL.md`
- **S2-82** Source quality: peer-reviewed over preprint over grey literature; flag sources older than 10 years unless seminal, self-citation above 15%, and "vibe citing" (a mash-up of real papers). → `references/revision.md#c4-citation--reference-check`

## G. Institutional facts and variable coding (core C-65 to C-68; Seat 2 owns the coding side)

- **S2-84** For every treatment, regime or "mandatory/voluntary" variable, build a year-by-unit coding table and check it against the rule's effective date (core C-66): no unit coded treated before its rule applied, every control unit checked for its own rule in the sample period. Why (example, BAI_VALUATION 2026-10): a Singapore 2014-2016 miscoding survived two full panels and changed p from 0.023 to 0.300. → `references/cards/core.md#g-institutional-facts-and-variable-coding`
- **S2-85** When coding precedes or contradicts the rule, rerun the models with a timing-consistent recoding in a scratch copy, report old vs new estimates side by side, and rate it MAJOR (CRITICAL if the headline moves); the source date stays an `AUTHOR_INPUT_NEEDED` placeholder until the authors confirm it (core C-67). → `references/cards/core.md#g-institutional-facts-and-variable-coding`
- **S2-86** Check that provider or index methodology (ESG ratings, index constituents, disclosure scores) matches the years and universe the variable claims, quoted with source and date (core C-65). → `references/cards/core.md#g-institutional-facts-and-variable-coding`

## H. Resolved conflicts

- **S2-90** Hansen J: "p > 0.05 means valid" (panel-reference) vs "0.10-0.90, near 1 signals proliferation" (methods-gap-fill): the stricter band wins.
- **S2-91** RDD polynomial order: "order > 1 discouraged" (r-data) vs "never above 2" (aer-identification): local linear is the main estimate, quadratic only as a robustness row.
- **S2-92** Balance thresholds: |SMD| < 0.1 after matching (iv-reference) vs |Δ| < 0.25 normalized difference (econ-stats): 0.1 applies to matched samples, 0.25 to descriptive comparisons; report which.
- **S2-93** Results format in prose: t-statistics in parentheses (house style) vs CIs (aer-robustness): follow the journal and the tables; headline and null results also get a 95% CI.
